# SB Live Website

Official website for **SB Live** — Next-Gen Live Streaming & Creator Economy mobile application (`com.pigobdlive.app`).

## Features
- Built with **Next.js 14 (App Router)**, **React 18**, and **Tailwind CSS**.
- **Responsive & Performant:** 60fps GPU hardware-accelerated glassmorphism design.
- **Google Play Compliance Pages:**
  - Privacy Policy (`/privacy-policy`)
  - Terms of Service (`/terms-and-conditions`)
  - Community Guidelines (`/community-guidelines`)
  - Child Safety Standards & CSAM Policy (`/child-safety-standards`)
  - Content Moderation Policy (`/content-moderation-policy`)
  - Account Deletion Request Guide (`/account-delete`)
  - Data Deletion & Retention Policy (`/data-deletion-policy`)
  - DMCA & Copyright Policy (`/copyright-policy`)
  - In-App Purchase & Refund Policy (`/refund-policy`)

## Getting Started

### Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Static Build & Export
```bash
npm run build
```
Generates pure static files in the `/out` directory ready for deployment on any web server or cPanel hosting.
